# АгроСервис-Батыс — кинематографический промо-сайт

Одностраничный **кинематографический промо-сайт** для ASB Group /
ТОО «АгроСервис-Батыс» (г. Уральск, ЗКО). Главный экран — «промо-ролик»
**золотых полей пшеницы и подсолнечника** на закате, который проигрывается
прямо в браузере: это не видеофайл, а **процедурная сцена на Canvas 2D**,
поэтому страница:

- **самодостаточна** — один файл `index.html`, открывается двойным кликом,
  без сервера, CDN, видеофайлов и зависимостей;
- **чёткая в любом разрешении** (Retina/4K) и лёгкая по весу;
- бесшовно зациклена и уважает `prefers-reduced-motion`.

## Что внутри ролика

- 🌾 **Пшеница** — 5 параллакс-полос колосьев, колышущихся на ветру с
  порывами (гасты), с подсветкой от низкого закатного солнца;
- 🌻 **Подсолнечник** — крупные цветы на переднем плане, головы повёрнуты
  к солнцу, лепестки бликуют со стороны света;
- ☀️ закатное небо, солнечный диск, god-rays, дымка над горизонтом;
- ✨ подсвеченная сзади пыльца/пыль, размытый передний план (depth of field);
- 🎞️ кинообработка: цветокор, виньетка, плёночное зерно, чёрные
  кинополосы (letterbox).

Поверх — «трейлер» из **титров-сцен** (4 карточки), HUD с прогрессом
и кнопками **пауза / с начала**, а ниже — полноценный лендинг (о компании,
культуры, технологии, контакты) с реальными цифрами хозяйства из дашборда
(66 единиц техники, 40+ видов, 1161 позиция на складе).

## Запуск

Просто откройте `cinematic-promo/index.html` двойным кликом — или залейте
файл на сайт как есть.

```bash
# при желании — через локальный сервер
cd cinematic-promo
python3 -m http.server 8080   # http://localhost:8080/
```

## Производительность

Сцена останавливается (фиксирует кадр), когда пользователь прокручивает
страницу вниз к контенту, и при паузе ролика — чтобы не нагружать CPU/GPU.
Плотность колосьев и число частиц масштабируются по ширине экрана.

## Настройка

Открыть `index.html` и поправить:

| Где | Что меняет |
|-----|------------|
| `cards` в HTML (`[data-card]`) | тексты титров промо-ролика |
| `DUR` (контроллер трейлера) | длительность одной сцены, мс |
| `build()` → `bands`, `suns`, `motes` | плотность пшеницы, число подсолнухов и пыльцы |
| `sky()` / `sun()` | палитра неба и закатного света |
| секции в `<main>` | контент лендинга (цифры, культуры, контакты) |

> Хотите фотореалистичный AI-видеоролик вместо процедурной сцены —
> сгенерируйте клип (Veo / Sora / Runway / Kling) и подставьте его в
> `#stage` как `<video autoplay muted loop>` вместо `<canvas id="field">`.
