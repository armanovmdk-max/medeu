# Видео-фон промо-сайта

Положите сюда видеоролик поля — он автоматически станет кинематографическим
фоном главного экрана (Canvas-сцена останется как fallback, если файла нет).

Имена файлов (любой из них; `.webm` грузится первым, `.mp4` — запасной):

```
assets/field-promo.webm
assets/field-promo.mp4
```

Рекомендации к клипу:
- горизонтальный 16:9, 1080p или 4K, 8–15 секунд, бесшовный луп;
- золотой час, пшеница/подсолнечник, медленное движение камеры;
- без звука (фон проигрывается в `muted`-режиме);
- mp4 (H.264) для совместимости; webm (VP9) — меньше вес.

## Без файла — тоже работает

Не обязательно ничего класть в репозиторий: на сайте есть кнопка **🎬**
(внизу слева, рядом с паузой) — она открывает выбор файла и проигрывает
**любой ваш локальный клип** как видео-фон прямо в браузере, офлайн, без
загрузки на сервер.

## Где взять ролик

- снять дрон/камерой ваши настоящие поля (лучший вариант для бренда);
- сгенерировать ИИ-клип (Higgsfield/Veo/Kling) — нужен платный баланс
  кредитов; промпт для генерации есть в корневом `README.md` проекта.
