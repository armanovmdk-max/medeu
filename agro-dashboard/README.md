# Agro-Logistics — дашборд управления агроскладом

Премиальный **glassmorphism-дашборд** учёта ТМЦ для ASB Group / ТОО «АгроСервис-Батыс»
(г. Уральск, ЗКО). Редизайн рабочего экрана `asbwork.kz/dashboard`: эстетика взята из
брифа (стеклянные панели над агрополем на закате, зелёно-золотой бренд), а функция и
данные — из реального дашборда.

> 📄 Полный разбор «вопросы → ответы → анализ → варианты → выбор» — в **`РЕШЕНИЕ.md`**.

## Что внутри

```
agro-dashboard/
├── dashboard.html   # ⭐ весь дашборд в одном файле — открыть двойным кликом
├── РЕШЕНИЕ.md       # анализ, 3 варианта и обоснование выбора
└── README.md
```

Один самодостаточный HTML-файл: **без сервера, CDN и зависимостей**, фон рисуется
чистым CSS (никаких внешних картинок/видео) — как и прошлые поставки в этом репозитории.

## Возможности

- Светлая **premium-glass** тема по умолчанию + рабочая **тёмная** (JARVIS), выбор сохраняется.
- Переключатель разделов **Запчасти / ГСМ / Химия** на одном экране.
- KPI-карточки со спарклайнами, area-график динамики стоимости, donut структуры остатков,
  столбчатый график заявок по статусам, таблица последних заявок со статус-бейджами.
- SVG-иконки, контраст ≥ 4.5:1 в обеих темах, табличные цифры, `prefers-reduced-motion`,
  адаптив 375 → 1440px.

## Запуск

Откройте `dashboard.html` двойным кликом — или залейте файл на сайт как есть.

```bash
# при желании — через локальный сервер
cd agro-dashboard
python3 -m http.server 8080   # http://localhost:8080/dashboard.html
```

## Данные

Раздел **«Запчасти» — реальные цифры** с дашборда (1161 позиция, 76 115 977 ₸, 20 «нет в
наличии», 66 единиц техники; заявки и таблица — со скриншота). Разделы **«ГСМ» и «Химия» —
иллюстративные** (помечены в интерфейсе), структура готова под подстановку реальных данных:
правьте объект `SECTIONS` в `<script>` внутри `dashboard.html`.
