# Agro-Logistics — анализ, варианты и решение

**Проект:** редизайн дашборда управления агроскладом
**Заказчик:** ASB Group · ТОО «АгроСервис-Батыс» (г. Уральск, ЗКО)
**Дата:** 23.06.2026
**Исходные данные:** скриншот текущего дашборда `asbwork.kz/dashboard` + два промта (Midjourney-стиль) на «Agro-Logistics» glassmorphism-интерфейс с разделами Spare Parts / Chemicals / Fuel.

Задача была поставлена открыто: *«Сам определи вопросы, сам дай обоснованные ответы, проведи анализ, разработай несколько вариантов, выбери оптимальный, оформи профессионально»*. Ниже — полный цикл.

## 1. Вопросы, которые нужно было прояснить (и обоснованные ответы)

| # | Вопрос | Обоснованный ответ |
|---|--------|--------------------|
| В1 | **Что является продуктом — картинка или рабочий интерфейс?** | Промты описывают «парящий стеклянный UI над полем» — это *концепт-арт*, не рабочий продукт. Скриншот же показывает реальный **B2B-дашборд учёта ТМЦ**. Вывод: нужен **рабочий редизайн дашборда**, который берёт *эстетику* из промтов, но *функцию и данные* — из реального экрана. |
| В2 | **Кто пользователь и в каком контексте работает?** | Кладовщик, снабженец, механик, руководитель хозяйства. Контекст — ежедневная работа, часто с обычного офисного ноутбука (это видно по скриншоту — Windows, не топовое «железо»). Значит: высокая читаемость, плотность данных, быстрая загрузка важнее «вау-графики». |
| В3 | **Какие данные и разделы реальны?** | Со скриншота: раздел **Запчасти** — 1161 позиция, 76 115 977 ₸, 20 «нет в наличии», 66 единиц техники (40 видов); заявок 51 (в работе 9, выполнено 15, мои 0); таблица последних заявок со статусами «У снабжения / На согласовании». Из промтов: нужны ещё разделы **ГСМ** (Fuel) и **Химия** (Chemicals). |
| В4 | **Достижима ли «фотореалистичная сцена с дроном» в вебе?** | Нет — как уже зафиксировано в README прошлых наработок, фотореализм уровня Unreal в реальном времени в браузере недостижим, а тяжёлый фон вредит рабочему инструменту. Берём из промтов **настроение** (поле, закат, glassmorphism, зелёно-золотая палитра), а не буквальную сцену. |
| В5 | **Светлая или тёмная тема?** | На скриншоте реальный дашборд **тёмный**, но в навбаре есть переключатель ☀️. Промты требуют **светлый** премиум-glass. Ответ: делаем **обе** — светлая premium-glass по умолчанию + рабочая тёмная тема с сохранением выбора. |
| В6 | **Технические ограничения и преемственность?** | В репозитории уже есть две самодостаточные one-file поставки (`agro-hologram-bg`, `cinematic-promo`) с брендом ASB Group (gold/amber/green, шрифт Inter). Логично продолжить тот же подход: **один HTML-файл, без сервера, CDN и зависимостей**, на том же бренде. |
| В7 | **Чем мерить успех?** | Читаемость (контраст ≥ 4.5:1), скорость (нет тяжёлых ассетов), узнаваемость бренда, доступность (клавиатура, reduced-motion), адаптивность (375 → 1440px), и «премиальность» картинки из промтов. |

## 2. Анализ текущего состояния (по скриншоту)

**Сильные стороны:** информация по делу, есть KPI-карточки, таблица заявок, переключатель темы и уведомления.

**Слабые стороны / зоны роста:**
1. **Плоская иерархия** — KPI-карточки и блоки заявок выглядят одинаково «весомыми», взгляду не за что зацепиться.
2. **Нет визуализации** — только числа, ни одного графика: не видно динамики стоимости, структуры остатков, распределения заявок по статусам.
3. **Монотонный тёмно-синий фон** без связи с агро-брендом (поле, зерно, закат).
4. **Разделы Склад/ГСМ/Химия** не сведены в один обзорный экран — приходится переключать страницы.
5. **Типографика данных** — без табличных цифр (числа «прыгают»), статусы — текстовые пилюли без визуального кода.
6. **Премиальности из промтов нет** — интерфейс утилитарный.

## 3. Разработанные варианты решения

### Вариант A — «Light Premium Glass» (буквально по промтам)
Светлый дашборд: размытое поле подсолнухов/пшеницы на закате, стеклянные полупрозрачные панели, зелёно-золотые акценты, мягкие тени.
- ➕ Точно отвечает промтам, «продающая» премиальная картинка, отлично для презентаций/маркетинга.
- ➖ На слабых экранах backdrop-blur может подтормаживать; яркий фон чуть снижает скорость чтения плотных таблиц.

### Вариант B — «Dark Ops Console» (JARVIS / как сейчас)
Тёмный центр управления, неоновые линии, как в текущем дашборде и в наработке `agro-hologram-bg`.
- ➕ Низкая утомляемость глаз при долгой работе, эффектно, преемственно с текущим экраном.
- ➖ Хуже для печати/выгрузок и при ярком дневном свете в поле; не отвечает «светлому» промту.

### Вариант C — «Clean Enterprise Light» (рекомендация дизайн-движка)
Плоский светлый интерфейс, slate + stock-green, максимум плотности и скорости, минимум эффектов (по рекомендации `ui-ux-pro-max`: индустриальный slate + зелёный, антипаттерны — лишний декор и сложные тени).
- ➕ Самый быстрый и доступный, идеален для ежедневной плотной работы.
- ➖ «Дёшево» выглядит, не отвечает премиальному запросу промтов, слабая узнаваемость бренда.

## 4. Выбор оптимального решения

**Выбран гибрид A × C с переключателем на B.**

Обоснование: ни один «чистый» вариант не закрывает все критерии из В7 сразу.
- Берём **визуальный язык A** (glassmorphism, агро-фон, бренд-палитра) — это прямой ответ промтам и «премиальность».
- Берём **дисциплину C** (табличные цифры, контраст ≥ 4.5:1, лёгкость, отсутствие тяжёлых ассетов, SVG-иконки вместо эмодзи) — это закрывает ежедневную работу и доступность.
- Оставляем **B как переключаемую тёмную тему** — закрывает усталость глаз и преемственность с текущим экраном, тем более переключатель уже есть в реальном навбаре.

Ключевое инженерное решение: **фон рисуется чистым CSS** (закатное небо + поля + размытие-вуаль), без единого внешнего изображения и без видео — поэтому поставка остаётся **одним самодостаточным HTML-файлом**, как и прошлые две, и при этом «премиальной».

## 5. Что реализовано (`dashboard.html`)

Один файл, без сервера/CDN/зависимостей. Открывается двойным кликом.

- **Шапка-бренд** ASB Group + Agro-Logistics, меню (Дашборд / Склад / Заявки / ГСМ / Каталог), переключатель темы (с сохранением в `localStorage`), уведомления, профиль.
- **Переключатель разделов** Запчасти / ГСМ / Химия — один экран, мгновенное переключение данных.
- **Строка статуса** с «живым» индикатором онлайн и реальными цифрами склада.
- **4 KPI-карточки** с иконками, трендами и мини-спарклайнами (позиции, стоимость, нет в наличии, техника).
- **График динамики** стоимости склада (area-chart + столбцы поступлений, анимация линии).
- **Donut + список** структуры остатков по группам.
- **Мини-карточки заявок** (всего / в работе / выполнено / мои).
- **Таблица последних заявок** с аватарами авторов и цветовыми статус-бейджами (реальные записи со скриншота).
- **Столбчатый график** распределения заявок по статусам.

**Качество (по чек-листу `ui-ux-pro-max`):** SVG-иконки (не эмодзи), контраст ≥ 4.5:1 в обеих темах, видимый focus-ring, табличные цифры, hover/active-состояния 150–300 мс, поддержка `prefers-reduced-motion`, адаптив 375 → 1440px, бренд-палитра ASB Group, обе темы протестированы вместе.

> Данные раздела **«Запчасти» — реальные** (со скриншота). **«ГСМ» и «Химия» — иллюстративные**, помечены сноской в интерфейсе; структура и форматы готовы под подстановку реальных данных из вашей системы.
